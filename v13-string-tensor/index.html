string.tensor

Eight strings are tuned to a quaternion-derived harmonic series. Each string's rest state is a specific quaternion rotation: string 1 = 0°, string 2 = 22.5°, up to string 8 = 157.5°. When you pluck a string, its quaternion is perturbed and oscillates back to rest via damped SLERP — the oscillation drives a Karplus-Strong-like synthesis. The rotation angle maps to frequency: smaller angles = lower pitch, larger angles = higher pitch. Neighboring strings are coupled via quaternion interpolation — plucking string 4 gently excites strings 3 and 5, creating sympathetic resonance.
