pulse.grid

This is a quaternion step sequencer. Each cell's position (row, column) maps to a quaternion via: q = (cos(row×π/16), sin(row×π/16), cos(col×π/16), sin(col×π/16)), normalized to unit length. The quaternion's w component determines the pitch (rows map to an 8-note scale from C3 to C5), while the imaginary magnitude |xi+yj+zk| determines the note's duration and attack. The sequencer plays left-to-right, with each column triggering simultaneously. Active cells produce triangle-wave tones with the quaternion-derived pitch and envelope.
