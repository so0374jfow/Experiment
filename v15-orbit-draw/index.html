Orbit.Draw — Quaternion Path Synthesis

Your drawn path is sampled at regular intervals and each point is mapped to a quaternion on the unit 3-sphere via stereographic projection. The path is then smoothed using SQUAD (Spherical Quadrangle) interpolation — the quaternion equivalent of cubic splines.

A point travels along this smooth quaternion curve, and at each moment its quaternion state determines the sound: w sets the fundamental frequency (110–440 Hz), the vector part (x, y, z) sets three harmonics whose amplitudes create the timbre.

Drawing fast creates wider orbits with more frequency variation; drawing slowly creates tight loops with subtle modulation. Multiple orbits create independent voices.
